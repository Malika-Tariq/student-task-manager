# Student Task Management System

# **Project Description**

A simple web application of student task manager using html, css and java script for managing tasks of students on daily basis. The project is built as pair-based Git and GitHub collaborative assignment. A user can write a task with a **title** and an optional **description**, and it appears immediately as a card in the task list. Each task can be marked as **completed** or **deleted** when it is no longer relevant. As the list grows, a **search box** filters tasks by title or description while the user types, without caring about capital letters.

# **Features**
- Add a task with a title and a description
- Display all tasks as cards
- Mark a task as completed, and undo it
- Delete a task
- Search tasks by title or description (not case-sensitive)
- Responsive layout for phones and small screens
- Automatic dark mode
#
# **Technologies**

- HTML for the page structure
- CSS for layout, styling and responsive design
- JavaScript for the task logic
- Git for version control
